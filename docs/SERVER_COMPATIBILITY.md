The local `kwamster/server-compatibility.json` inventory exposes versions, capabilities, modes, source, evidence category and limits. `Announcements.Rules` remains the host-scoped extension point. Host normalization handles case, a numeric port and one trailing dot; exact aliases exclude arbitrary subdomains and lookalikes such as `minemen.club.attacker.invalid`.

Unknown servers use generic combat capture when Automatic capture is enabled. Configured environments suppress ordinary combat starts, deaths/kill-based ends and inactivity-based ends. Missing signals never switch them to generic capture. Manual recording works on every host, including when Automatic capture is off. Disconnect/abandonment/resource interruptions are preserved separately from detected normal ends.

## Collecting additional evidence

1. Join the server and enter `/kwm diagnostics on` (off by default). Use `/kwm start` if automatic start recognition is unavailable.
2. Play through complete matches and rounds, including the final result. Write down the actual overall result, round results you know, order and approximate time. Do not substitute a round victory for a match victory.
3. Enter `/kwm end` to save manual capture, then `/kwm diagnostics off`. Copy evidence for analysis; preserve originals. Minecraft logs may omit titles/actionbar packets.
4. `/kwm diagnostics export` creates a local redacted fixture bundle. `export-names` retains host fields; `export-servers` retains names. Review before sharing. No upload occurs.
5. Inspect origins, rule, adapter ID/version, active policy and lifecycle decision. Schema 2 records policy-status changes, missing-start/end limitations and rejection reasons. Player/disguised/uncertain chat and unrelated/private text are filtered; numeric countdown/title noise is omitted. System-relayed private chat can use unknown conventions, so inspect before sharing.
6. Add exact observed whole-message rules, negative host/channel/participant tests, multi-round replay and documentation. A synthetic format is never evidence of server support.

Diagnostic captures rotate at 2,048 entries and checkpoint every five seconds. Storage work and serialization run on the bounded worker; raw captures stay local and are not automatically pruned. Source-referenced raw investigation and preservation hashes for this assignment remain in ignored `.local-diagnostics/0.1.5`. Public fixtures replace player identities and use relative times.
