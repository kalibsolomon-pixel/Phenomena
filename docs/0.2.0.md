# 0.2.0 — Phenomena rename, per-pixel renderer and Spxctra UI

Starting HEAD `1b5f85b860636488a02373ee43ea5be098fb13b9` (KWAMSTER 0.1.6 + notification hotfix), branch `codex/0.1.2-combat-corrections`, clean working tree. Local development milestone; no push, publication or installation into the owner's Aurora instance. Development artifact: `build/libs/phenomena-0.2.0.jar`.

Scope: project rename to **Phenomena** with forward-only data/config migration, PVPHQ notification-fix re-verification on the renamed tree, a per-pixel native renderer adapted from Aurora Client's coverage rasterization, and a Spxctra-language redesign of all six dashboard screens. Combat analytics definitions, capture policies, schemas 1–6 decoders, report format version 6 and the six configured-server environments are unchanged. See `PHENOMENA_MIGRATION.md` for the full rename inventory, renderer audit and UI change list.

## What changed

1. **Identity** — mod id `phenomena`, packages `dev.phenomena`, `/phenomena` command with `/kwm` as a deprecated redirect alias, `key.phenomena.open` keybind, `assets/phenomena` namespace, artifact `phenomena-0.2.0.jar`.
2. **Migration** — `kwamster/` data copies forward once (atomic temp-then-move, conflict-preserving, idempotent, `migration.json` marker); `config/kwamster.json` is read exactly once when `phenomena.json` is absent and never modified; legacy `.kwamster-owner` export markers keep establishing ownership. Receipt digests are unchanged, so migrated recordings are not re-exported.
3. **Renderer** — `dev.phenomena.gui.pixel.Pixel`: analytic rasterization in physical device pixels with exact sub-pixel coverage folded into alpha; rounded fills/outlines, circles, axis-aligned and diagonal AA lines, per-device-row gradients; ordinary batched `GuiGraphics.fill` submission under a `1/guiScale` pose. No shaders, framebuffers or GL state changes; vanilla-pipeline compatible by construction.
4. **UI** — Spxctra role tokens and geometry vocabulary; every component and chart repainted at device resolution; real toggle switches; settings regrouped into nine functional areas with the two inactivity timeouts explicitly separated; History drops the per-row action column in favor of the selection toolbar; elevated opaque popups and dialogs.

## Known limitations

- The original `C:\Dev\Kwamster` directory remains untouched until the owner removes it (an external session handle prevented an in-place rename; the verified copy-then-swap is documented in `PHENOMENA_MIGRATION.md` §2).

- Historical reports keep KWAMSTER branding as provenance; re-exporting a fight from History refreshes its branding.
- Live external PVPHQ acceptance remains owner testing, as in 0.1.6.
